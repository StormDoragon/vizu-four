Labeling sheet

Label blind. This page shows only each commit's metadata: message, author, date and files touched. It contains no classifier output. Please don't run the classifier or look at its results until you've finished.
  • Include in notes: do you want this change in the release notes you would publish for this range? One global yes/no.
  • Security-sensitive: should a maintainer look before this is described publicly? A conservative yes is fine.
  • Breaking: does this break existing users?
  • Category (optional): leave blank if it doesn't matter; inclusion is scored either way.
  • Skip only a commit you truly can't judge, with a reason of at least 10 characters. Skips are reported, never hidden.
  • Use the note for policy calls (reverts, typo fixes, dependency bumps) or anything a later reader needs.
Progress is kept in this browser while you work. Nothing is sent anywhere; you export the file yourself at the end.

Review record

The tooling checks these are filled in and well formed. It cannot check that the review really happened; that is what the record link is for.

Export

Export checks the same rules as the importer: every commit labeled or skipped with a reason, and the review record filled in. Save the file into src/lib/release/eval/reviewed/.
